# Beat Factory — Visual Redesign Roadmap

Documents:
- `ART_STYLE_GUIDE.md` (rules)
- `FULL_VISUAL_ASSET_LIST.md` (what is missing)
- `STUDIO_ART_PLAN.md`
- `CHARACTER_ART_PLAN.md`, together with `ARTIST_ART_PLAN.md`
- `CONCERT_ART_PLAN.md`
- `UI_REDESIGN_PLAN.md`

**Hard rules for every phase:**
- no gameplay systems deleted;
- economy unchanged;
- saves compatible;
- AdMob and localisation preserved;
- concept images are never treated as finished layered sprites;
- no generic placeholder art is shipped as "done".

## Phase 1 — Audit (✅ done in this planning task)

**Findings:**
- **Code-drawn art.** All art except the basement and the NØX stand-in is generated by code in a flat style:
  - `Scripts/Editor/Art/ArtGenerator.*.cs`, ~550 PNGs in `Art/Characters`, `Art/Environments`, `Art/Venues`, `Art/UI`, `Art/Effects`, `Art/Albums`.
- **Scene and prefabs.** One scene (`Scenes/Game.unity`), built by code; 5 prefabs (AlbumCard, ArtistCard, ProducerRow, ShopRow, StyleItemCard).
- **New-style art so far.** Basement main screen (painted art + live DAW, lamp and neon), NØX layered rig (stand-in parts), BOOSTS card.
- **Style inconsistency.** The flat procedural screens (studio card, producers, artists, concerts) now sit next to the painted basement. The redesign fixes this mismatch.

## Phase 8 — Mobile performance

**Today (measured):**
- the dev APK is 95.9 MB (before any new painted art);
- the basement texture is 864×1536 RGBA uncompressed (≈5 MB in memory);
- a real device frame rate has **not** been measured yet.

**Plan:**
- **Studio backgrounds.** ASTC 6×6, no mipmaps (≈2.5 MB each at 1440×2560); only the current studio loaded (Resources/Addressables).
- **Characters.** One atlas per artist (2048² ASTC ≈ 2.8 MB); load on demand.
- **Packaging.** Android App Bundle with install-time asset packs if the AAB exceeds 150 MB.
- **Measurement on the emulator + a real phone:**
  - Profiler: memory + frame time;
  - build-size report after every art phase.

**Done when:**
- 60 fps on a mid-range Android (e.g. 4 GB RAM, Mali-G57);
- texture memory < 150 MB;
- the AAB stays under 150 MB base.

## Phase 9 — Order of work (recommended)

1. **High-res basement + Bedroom Studio.**
   - Code: per-level studio art.
   - Proves the whole studio pipeline with 2 rooms.
2. **NØX production parts + portrait.** Proves the character pipeline end to end; then the DRIP STUDIO screen.
3. **Studios 3–10.** Art can run in parallel with steps 4–5.
4. **Producers (seated)** so the studios feel alive.
5. **UI skin + icons.** Fast visual consistency win.
6. **Hero artists → standard artists.**
7. **Venues + crowd atlas + aerial.**
8. **Performance pass + store screenshots.**

Each step ends with:
- tests (EditMode 21+);
- a Play Mode screenshot review;
- an APK on the emulator.
